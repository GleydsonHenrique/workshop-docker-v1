O que você vai praticar

  • ✓ Escrever um Dockerfile do zero, linha por linha
  • ✓ Entender imagem base, camadas e o que cada instrução faz
  • ✓ Copiar arquivos para dentro da imagem com COPY
  • ✓ Construir a imagem com docker build
  • ✓ Rodar e mapear portas com docker run -p
  • ✓ Testar tudo direto no GitHub Codespaces, sem instalar nada

Como rodar o laboratório

Siga na ordem. Cada passo depende do anterior.

  1. Abra no Codespaces

    No GitHub, clique em Code → Codespaces → Create codespace. O ambiente já vem com Docker pronto.

  2. Complete o Dockerfile

    Abra o arquivo Dockerfile na raiz e preencha os TODOs. Dica: a imagem oficial do Apache serve a pasta /usr/local/apache2/htdocs/.

  3. Construa a imagem

    No terminal do Codespaces:

    docker build -t workshop-apache .

  4. Rode o container

    Suba o container mapeando a porta 80 do Apache para a 8080:

    docker run -d -p 8080:80 workshop-apache

  5. Abra a porta 8080

    Na aba Ports do Codespaces, clique no ícone de globo da porta 8080. Esta página deve aparecer. Fim do desafio. 🐳
